# Branding Design Sources

## Official logo

- `physics-tracker-logo.svg` — canonical official Physics Tracker logo supplied by the design owner.
  This is an exact copy of the supplied SVG; do not redesign, recolour, reinterpret, or alter its
  appearance.
- `physics-tracker-logo-icon.png` — 1024×1024 transparent square master generated with Inkscape
  1.4.4 from the approved source using the existing square framing
  (`106.417,226.3185`–`793.7,913.6015` in source units), which crops only A4 page whitespace. The
  logo artwork and colours are unchanged.

The canonical source SHA-256 is
`6F5E18B8DEAAC9C1B67C6A9FBAC54C7746456861FA8F94C865FCC3A4D8D28235`.

## Runtime assets

- `public/favicon.png` — 512×512 browser favicon exported from the same square framing.
- `src-tauri/icons/` — generated with the Tauri CLI from `physics-tracker-logo-icon.png`:
  15 PNG files, one multi-size ICO, and one multi-size ICNS.

## Legacy design sources

The following older PH lettermark files are retained for historical reference only. They are not
used by the active V2 application, the favicon, or the installer:

- `ph-app-icon.svg` — previous application-icon design source.
- `ph-mark.svg` — previous primary PH lettermark source.
- `ph-mark-dark.svg` — previous dark-theme lettermark source.
- `ph-mark-light.svg` — previous light-theme lettermark source.
- `ph-sidebar.svg` — previous sidebar-mark design source.
- `ph-splash.svg` — previous splash-screen lockup source.

## Preservation

Do not delete these assets based only on unused-code or reference scans. The official logo and its
icon master are canonical; the legacy sources are retained as historical design records. Removal or
consolidation requires design-owner approval.
