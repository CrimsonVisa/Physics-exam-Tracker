# Branding Design Sources

These SVGs are the design-source files for the Physics Tracker identity. They are not imported by
the application at runtime. The in-app mark is drawn inline in `src/components/BrandMark.tsx`, and
`public/favicon.svg` is the runtime favicon referenced by `index.html`.

## Files

- `ph-app-icon.svg` — application icon design source. It is byte-identical to `public/favicon.svg`.
- `ph-mark.svg` — primary PH lettermark source.
- `ph-mark-dark.svg` — dark-theme lettermark source.
- `ph-mark-light.svg` — light-theme lettermark source.
- `ph-sidebar.svg` — sidebar-mark design source; the in-app sidebar mark is drawn inline.
- `ph-splash.svg` — splash-screen lockup design source.

## Preservation

Do not delete these assets based only on unused-code or reference scans. They are retained as
intentional design sources. Removal or consolidation requires design-owner approval.
