# Bundled Latin Modern fonts

These fonts are bundled locally so the application has consistent typography without any network
request.

## Sources

- Latin Modern Roman, Latin Modern Sans, and Latin Modern Mono, version 2.004 (OpenType):
  <https://www.gust.org.pl/projects/e-foundry/latin-modern>
- Latin Modern Math (OpenType), from the CTAN `lm-math` package:
  <https://ctan.org/pkg/lm-math>

The font files are unmodified. Only the regular, bold, italic/oblique, and bold-italic/oblique
variants used by the interface are included.
