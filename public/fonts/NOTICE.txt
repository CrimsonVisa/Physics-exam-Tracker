Computer Modern Unicode fonts
=============================

The application bundles Computer Modern Unicode (CMU) 0.7.0 locally:

- CMU Serif
- CMU Sans Serif
- CMU Typewriter Text

Source: https://cm-unicode.sourceforge.io/ (distributed via CTAN)
License: SIL Open Font License, Version 1.1
See OFL-1.1.txt for the required copyright and license notice.

No font is downloaded at runtime. Cambria Math and Segoe UI Symbol may be used as local fallback
glyphs for mathematical operators that CMU does not contain.
