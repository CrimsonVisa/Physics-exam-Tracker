## Method

- PDF text was extracted page-by-page; the first page of each document was rendered and visually checked for title, structure and source identity, with page text used for the detailed clauses.
- CSIR and JEST are audited at tracker topic granularity because the tracker topics are normalized splits of the PDF clauses; the JSON retains explicit subtopic fragments and the full page text. GATE 2025 is audited at explicit clause level, with GATE 2027 tracker-only content listed separately.
- TIFR is audited only at its eight explicitly listed broad areas. The document contains no detailed topic list, so no TIFR subtopic is treated as official.
- A row is `MATCH` only when the explicit reference content is represented without material loss. Broad or inferred content is never counted as an official detailed match.
